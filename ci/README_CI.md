# CLAW & CO. — Automated Godot Review Pipeline (Checkpoint CI-0)

**Status: prepared locally; not yet published or executed on GitHub.** The source is the owner's R4.1 parser-fixed baseline; no R5.1 art rewrite is included.

## One-time setup

1. On GitHub create a **private** repository named `claw-and-co` (no README/.gitignore/license, to keep it empty).
2. Extract this ZIP. `project.godot` must be in the same directory as `.github/` and `ci/`.
3. Open a terminal in that directory; execute:

   ```bash
   git init
   git add .
   git commit -m "CI-0: Preserve R4.1 and add Godot visual review pipeline"
   git branch -M main
   git remote add origin https://github.com/OWNER/claw-and-co.git
   git push -u origin main
   ```

   Replace OWNER with your actual GitHub username. Authenticate using Git Credential Manager or GitHub Desktop; do not paste a personal token into chat.
4. Open repo > **Actions** > `Claw & Co. | Godot 4.7.2 Visual Review`. The first push normally triggers it. If necessary use **Run workflow**. GitHub may require enabling Actions in a new private repository.
5. On the workflow run, open **Artifacts** and download `clawco-godot-review-N`. It contains import logs, all headless test logs, five genuine 1280x720 Godot frames, a ten-second native-engine MP4, renderer metadata, and `REVIEW.md`.

## What is and is not verified

The runner downloads the **official Godot 4.7.2 stable** binary and compares SHA-256 against the GitHub release asset metadata. Tests launch Godot 4.7.2. Real graphics captures run with Mesa/llvmpipe under Xvfb using `gl_compatibility` for repeatable CPU rendering; native Windows Forward+ glow and frame-rate quality still require additional owner validation. Captures are correctly labeled and never substituted with artwork composites.

Successful pipeline execution DOES NOT mark the R4 character-animation visuals accepted. The strict `RunR4ArtAcceptance.gd` check is recorded as a known blocker. Any failing import/test/capture marks GitHub Actions red (evidence still uploads).

**Screenshots are generated by `ci/CaptureReview.gd` from Godot's actual viewport** at ticks 0, 240, 900, workshop, 1800 using the authored Stage 1 command fixture. `--write-movie` records actual runtime frames for ten seconds. The movie is encoded to MP4 with FFmpeg. No browser export is needed.

## Security/maintenance

- Keep the repo private: source and unreleased art are proprietary.
- `.godot/`, logs, and generated previews are excluded from Git. Capture artifacts expire after 14 days.
- CI triggers on `main`, `r5/**`, `ci/**`, PRs, and manual dispatch.
- Keep R5 work on separate branches and preserve baseline hashes.
- For best visual parity, a future Windows Forward+ GPU runner can be added separately; do not silently mix its results with the compatibility capture.
- If Godot scripts fail on Linux, review the saved errors. The initial run is a **pipeline bring-up**, not presumed green.
